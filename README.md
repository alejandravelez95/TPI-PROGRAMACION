**Introducción:**

El presente trabajo tiene como objetivo desarrollar un sistema de inventario de herramientas utilizando Python.
El programa permite cargar nuevas herramientas, visualizar el inventario completo, consultar el stock de una herramienta especifica y también genera un reporte de los productos que se encuentran sin stock.
